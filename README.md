# InsurePlanCal V2

เครื่องมือภายในสำหรับประเมินเบี้ยมาตรฐานรายปีจากเอกสาร AIA ที่ผู้ใช้จัดเตรียม

## รองรับ

26 แบบ/ระยะชำระ จากตารางใน 20 เอกสาร:
- Pay Life Plus 10/15/20 Pay, Pay Life 10/15/20 Pay, Senior Happy
- Protection 65, Saving Sure, 5 Pay 10, Endowment 15/25
- Annuity Fix, Annuity Sure 9 Pay/ชำระถึงอายุ 60
- Health Happy, Health Saver, Health Starter Begin/Balanced, Health CI Hero Begin/Balanced, Infinite Care
- CI Plus, Multi-Pay CI Plus + Total Care, Care for Cancer, HB Extra, TPD

เลือกสุขภาพได้หนึ่งรายการและเพิ่มสัญญาเพิ่มเติมได้หลายรายการ รองรับการประเมินเบี้ยรายตัวโดยไม่เลือกแบบหลัก แหล่งข้อมูลเชื่อมกลับเอกสารต้นฉบับทุกแบบ

## ขอบเขต

ยัง **ไม่ครบทุกแผน** ในเอกสารทั้งหมด: `data/coverage.json` แสดงสถานะ 99 เอกสาร รวมเอกสารฝึกอบรม/คู่มือซึ่งไม่ใช่ผลิตภัณฑ์แยก

ยังไม่เปิด Unit Linked/UDR, Health Happy Kids, Term, CI SuperCare/Prestige, CI ProCare, Legacy, Excellent, Lifetime Income, อุบัติเหตุ, ยกเว้นเบี้ย และผลิตภัณฑ์อื่นที่ยังตรวจตารางหรือเงื่อนไขไม่ครบ ไม่ประมาณหรือแทนค่าของแบบอื่น

- ตารางมาจากข้อความเอกสารที่อัปโหลด ยังไม่ได้ตรวจภาพตารางต้นฉบับทุกหน้าและไม่ได้ยืนยันว่าเป็นอัตราปัจจุบัน
- ไม่รวมส่วนลด Vitality เบี้ยเพิ่ม หรือวิธีแปลงงวดชำระ
- ทศนิยม 2 ตำแหน่งเป็นการคำนวณจากอัตรา ไม่ใช่การยืนยันวิธีปัดเศษของบริษัท
- ผลรวมไม่ยืนยันการแนบสัญญาร่วมกัน เกณฑ์ทุนรวม รายได้ อาชีพ และรับประกันสุขภาพยังต้องตรวจบริษัท
- Annuity/Senior ปิดการรวมกับสุขภาพ/สัญญาเพิ่มเติมที่ยังไม่ได้ยืนยัน
- อายุ 0 ต้องยืนยันอายุจริงอย่างน้อย 15 วัน
- เมื่อข้อมูลไม่ถูกต้อง แสดงข้อผิดพลาดและไม่แสดงผลรวม

## โครงสร้าง / ตรวจสอบ

`calculator.js` เป็นฟังก์ชันคำนวณที่ไม่มี DOM; `app.js` เป็น UI; `data/products.json` เป็นตารางที่เปิดคำนวณ; `data/coverage.json` เป็นบัญชีเอกสาร

```sh
node tests/calculator.test.js
node --check app.js
```

ทดสอบ 6,234 ชุดอายุ/เพศ/แผน พร้อมตัวอย่างในโบรชัวร์ จุดส่วนลด ขอบเขตอายุ หน่วยทุน และข้อมูลที่ต้องปฏิเสธ ยังไม่ได้ทดสอบ UI ด้วยเบราว์เซอร์จริงในรอบนี้

นำเข้าตารางอีกครั้งด้วย `python scripts/import-rates.py /path/to/sources.json` ใช้ mapping คอลัมน์ที่กำหนดชัดเจนและตรวจจำนวนค่า ห้ามเพิ่มผลิตภัณฑ์ด้วยการเดาโครงสร้างตาราง

เผยแพร่ static assets โดยคัดลอก index.html, app.js, calculator.js และ JSON ข้อมูลที่ใช้แสดงผลไปยัง dist
