# InsurePlanCal

เครื่องคำนวณเบี้ยสำหรับทีม CatNay

## V1
เปิด index.html ในเบราว์เซอร์ รองรับอายุประกัน 11–75 ปี เบี้ยมาตรฐานรายปี Pay Life Plus (Non Par) 20 Pay และ Health Happy แผน 1/5/15/25 ล้านบาท

Flow: เพศและอายุประกัน → ทุนประกันหลัก → แผนสุขภาพ → สรุปเบี้ย → คัดลอกข้อความ

เคสตรวจสอบ: ชาย 57 ปี ทุน 150,000 + Health Happy 5 ล้าน = 8,118 + 42,300 = 50,418 บาท/ปี

ยังไม่รวม Vitality, เบี้ยเพิ่ม, งวดชำระอื่น, การพิจารณารับประกัน หรือการยืนยันอัตราปัจจุบัน ทุนส่วนลด 500,000–699,999: 1 บาท/ทุน 1,000; 700,000 ขึ้นไป: 1.5 บาท/ทุน 1,000

## ข้อมูลทั้งหมดจาก Drive
สำรวจ PDF ในโฟลเดอร์ AIA/แบบประกันแบบ recursive พบ 99 ไฟล์ นำเข้าข้อความได้ 96 ไฟล์ ดู data/catalog.json และ data/sources/part-01.json ถึง part-10.json

ข้อมูล sources เป็นข้อความที่สกัดจาก PDF ไม่ใช่ตารางคำนวณที่ผ่านการตรวจครบ การเรียงคอลัมน์และตัวอักษรไทยอาจคลาดเคลื่อน ห้ามนำเข้าเป็นตัวเลขคำนวณอัตโนมัติโดยไม่ตรวจเอกสารต้นฉบับ แยกแบบหลัก/PPR/UDR และรุ่นเอกสารก่อนเปิดใช้งาน

3 ไฟล์ไม่มีข้อความ: BROCHURE_Vitality_V80_2025(TH)_20250925.pdf, Term80_Premuim_20200918.pdf, AIAHealthPlus_Brochure_20210617.pdf ต้องดึงต้นฉบับและตรวจเพิ่มเติม

## ตรวจสอบ
สูตรผ่านการตรวจ 650 ชุดอายุ/เพศ/แผน รวมส่วนลดและข้อมูลนอกช่วง ยังไม่ได้ตรวจ UI ด้วยเบราว์เซอร์จริงเพราะสภาพแวดล้อมไม่มี Chromium

## การเผยแพร่
Repository นี้ใช้ภายในแบบ Private ยังไม่ได้ deploy เว็บออนไลน์ อย่านำเอกสารหรือตารางเบี้ยเผยแพร่สาธารณะก่อนยืนยันสิทธิ์ การ deploy static web อาจเปิดเผยข้อมูลใน browser แม้ repository เป็น Private
