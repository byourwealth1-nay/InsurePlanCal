# InsurePlanCal · Traditional / PPR

เครื่องมือประเมินเบี้ยมาตรฐานรายปีจากเอกสาร AIA ที่ผู้ใช้จัดเตรียม เผยแพร่ผ่าน GitHub Pages

## หน้าคำนวณ

- กรมธรรม์หลัก 33 แบบ/ระยะชำระ และสัญญาเพิ่มเติม PPR 30 ตัวเลือก
- สุขภาพ โรคร้ายแรง อุบัติเหตุ ชดเชยรายได้ และยกเว้นเบี้ยอยู่ในหมวดเดียว เพิ่มได้หลายรายการ
- CI Topup แสดงทุน 40% ของ CI Plus อัตโนมัติ ปรับตามทุน CI Plus และลบพร้อมกันเมื่อผู้ใช้ลบ CI Plus
- PB/PBCI ใช้เพศและอายุผู้ชำระเบี้ย แยกจากเด็กที่เอาประกัน ใช้เบี้ยหลักและระยะคุ้มครองที่คำนวณจากระยะชำระเบี้ยหลัก, 25 ลบอายุเด็ก, และ 80 ลบอายุผู้ชำระเบี้ย ตามคู่มือ
- WPCI ใช้เบี้ยหลักต่อปีและระยะชำระเบี้ยหลัก รองรับเฉพาะช่องอัตราที่มีในคู่มือ ไม่ประมาณช่องว่าง/ระยะอื่น และป้องกันการเพิ่มซ้ำเมื่อ Pay Life Plus รวม WPCI แล้ว
- Health Cancer ใช้ตาราง 10 หน่วย มีอัตรามาตรฐานและไม่สูบบุหรี่ตามที่พิมพ์ในคู่มือ
- WP เพิ่มเป็นช่องกรอกเบี้ยจากใบเสนอขายบริษัท เพราะเอกสารที่ได้รับไม่มีตารางเบี้ยซื้อ WP ช่องเริ่มต้นว่างและไม่รวมยอดจนผู้ใช้กรอก ไม่สมมุติเป็นเบี้ยฟรี

## ขอบเขต

Unit Linked/UDR อยู่นอกขอบเขตนี้ `data/coverage.json` แสดงรายการในขอบเขตและระบุ WP ว่าใช้เบี้ยที่ผู้ใช้กรอก

ไม่รวม Vitality เบี้ยเพิ่ม งวดชำระอื่น หรือ Preferred Rate ต้องตรวจเกณฑ์การแนบ ทุนรวม รายได้ อาชีพ การรับประกัน และอัตราปัจจุบันกับบริษัท ผลรวมไม่ใช่การยืนยันว่าแนบทุกสัญญาร่วมกันได้

อายุ 0 ต้องมีอายุจริงอย่างน้อย 15 วัน หากข้อมูลไม่ถูกต้องหรือไม่มีอัตราในตาราง เว็บแสดงข้อผิดพลาดและไม่รวมยอด เบี้ยปัดทศนิยม 2 ตำแหน่ง วิธีปัดเศษจริงต้องตรวจใบเสนอขายบริษัท

## ตรวจสอบ

```sh
node --check app.js
node --check calculator.js
node tests/calculator.test.js
python scripts/audit-benefit-plus.py /path/to/sources.json
```

ทดสอบ 14,144 ชุดอายุ/เพศ/แผน, 2,624 ช่องตารางยกเว้นเบี้ย, ตัวอย่างเบี้ยในเอกสาร, การแยกเพศผู้ชำระเบี้ย, ทุน CI Topup, การกรอก WP และการปฏิเสธอัตราที่ไม่มี ตรวจ Benefit Plus 14 แบบ/ระยะชำระ รวม 1,362 ค่า และตรวจ CI SuperCare Prestige กับเบี้ยโบรชัวร์ 792 ค่าในรอบก่อน

`calculator.js` ไม่มี DOM; `app.js` จัดการ UI; `data/products.json` เก็บอัตราและเงื่อนไขพร้อมแหล่งอ้างอิง

สคริปต์นำเข้าเพิ่มเติมต้องใช้เอกสารต้นฉบับ/ข้อความ PDF แบบรักษาตำแหน่ง ไม่เดาลำดับคอลัมน์:

```sh
python scripts/extend-ppr.py /path/to/sources.json /path/to/pdf-layout-directory
python scripts/import-waivers.py /path/to/sources.json /path/to/waiver-layout.txt
```

การรันตัวนำเข้าเริ่มต้น `import-rates.py` จะสร้างเฉพาะชุดตั้งต้น ไม่ใช่ทุกผลิตภัณฑ์ อย่าใช้แทนข้อมูลปัจจุบันโดยไม่รันและตรวจขั้นตอนเพิ่มเติม
